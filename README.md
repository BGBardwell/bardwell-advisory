# Bardwell Advisory website

One-page static website for GitHub Pages.

## Before publishing
- Contact email is set to `info@bardwelladvisory.com`; verify it receives messages before publishing.
- Review all services and credentials for accuracy.
- Do not change domain DNS until the GitHub Pages preview is approved.

## GitHub Pages
Upload `index.html` and the `assets` folder to the root of your public repository. In Settings > Pages, select Deploy from a branch, `main`, `/ (root)`. Preview at `https://YOUR-USERNAME.github.io/bardwell-advisory/`.
